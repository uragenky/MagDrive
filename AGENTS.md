# Project Guidelines: MagDrive

## Language Policy
- Codebase files, source code, comments, logs, and error messages MUST be written in English.
- User Interface (UI) copy, labels, tooltips, dialogs, and button texts MUST be written in English.
- Documentation, READMEs, guides, and specifications MUST be written in English.
- User conversation responses remain in the user's preferred language (Indonesian or English).
